ある程度のCNSの知識がないと難しいかもです
なお、相手が確認用のヘルパーを射出してから専用アニメを表示させるので、普段から26000~26500番を避ける必要はないありません

動作確認の際は、アレッシー側のconfig.txtを開いて子供化の自動解除を切ってしまうと楽です

---２---
子供化対応するよーっていうサインの役割を持つヘルパーを射出します。アレッシー側はこのヘルパーが存在することを感知して相手に対応アニメを表示させます。
[Statedef -2]のどこか(無ければ作る)に以下の記述をコピペしてください

;ここから

;■対アレッシー　子供化対応確認用ヘルパー
[state -2, helper]
type = helper
triggerall = !numhelper(815778369)
triggerall = (p2name = "alessi" || p4name = "alessi")
trigger1 = movetype = H
trigger1 = stateno = 200002
helpertype = normal
name = "check"
stateno = 815778369
id = 815778369
pos = 999999999,-999999999
postype = p1
ownpal = 1
keyctrl = 0
pausemovetime = 999999999
supermovetime = 999999999

[State -3, 関係無いステートに行かないように]
type=changestate
trigger1= ishelper(815778369)
trigger1= stateno!=815778369
value=815778369

;ここまで

---３---
確認用ヘルパーのステートを作成します
CNS内の[Statedef -1](技ステートとか書く所)のどこかに以下の記述をコピペ
anim = xxxx のxxxxには●準備●で用意した空アニメのアニメNoを入れてください

;ここから
;---------------------------------------------------------------------------
;対アレッシー　子供化対応確認用ヘルパー
[Statedef 815778369]
ctrl = 0
anim = xxxx;空アニメ(何も表示しないアニメを指定します)

[State 0, assert]
type = assertspecial
trigger1 = 1
flag = invisible

;消去
[State 0, assert]
type = destroyself
trigger1 = (root,stateno != [200000,205151])

;ここまで


●攻撃の作成●
いよいよ攻撃の作成です

・子供化状態では、立ちしゃがみジャンプそれぞれ弱中強攻撃が存在しますが原作では大方のキャラは
　どこかで使い回ししてます

・判定や発生、威力等性能の調整はアレッシーあたりを参考にしておくと無難です
　気を使って調整する必要はありませんが、あくまで逃げるべしな状態であることを忘れずに

・地上攻撃中に子供化が戻ることもあります。
　攻撃動作途中で中断されても大丈夫な作りにしてください
　その他諸々は-2stateでの管理を
